# SignalIQ-Inspired High-Tech Portfolio

An Awwwards-grade portfolio web application built with the design aesthetics, editorial serif-sans typography pairings, glowing neon matrices, real-time telemetry ribbons, and deep interactive widgets inspired by [Pine Labs’ SignalIQ](https://marketing.pinelabs.com/signaliq).

---

## Key Features & Design System

1. **Editorial & Tech Typography Pairing**:
   - *Platypi / Instrument Serif* italic accents (`/Introducing/`, `MODERN SCALE`, `THE GAP`).
   - *Space Grotesk* uppercase tracked display headers (`PRECISION ARCHITECTURE`, `01`, `02`, `03`).
   - *JetBrains Mono* for real-time telemetry stream tickers, latency badges, and CLI commands.

2. **Visual Atmosphere & Color Scheme**:
   - Deep Obsidian background (`#05070A`, `#080B10`) with radial cursor spotlights.
   - Electric Emerald Signal (`#00F29D`) and Laser Cyan (`#00D2FF`) glowing accents.
   - Glassmorphic floating nav pill with live availability beacon.

3. **Interactive Components**:
   - **Hero Signal Profiler**: Live tabbed role switcher with real-time code traces, latency metrics, and copy actions.
   - **The Comparator ("A Gap in the Architecture is a Gap in the Truth")**: Interactive diagnostic telemetry comparison between Legacy vs Signal Architecture.
   - **Bento Pillars (01, 02, 03)**: Numbered precision engineering pillars with micro-chips (`L1`, `L2`, `RECURRENCE`, `HEALTH`) and interactive payload visualizers.
   - **Interactive CLI Terminal**: Interactive terminal shell supporting commands (`help`, `skills`, `benchmark`, `projects`, `stats`, `contact`, `clear`).
   - **Featured Projects Showcase**: Production case studies with architecture detail modals.
   - **Tactile Web Audio Feedback**: Synthesized subtle audio feedback on toggles and clicks (with instant mute control).
   - **SignalIQ FAQ Accordion**: Smooth collapsible FAQ accordion with glowing hover states.
   - **Direct Contact & Email Copy**: Modal transmission form and one-click copy to clipboard with toast notifications.

All personal details, case studies, metrics, and FAQs are centralized in [data.js](file:///c:/Users/HP/Downloads/Development/data.js). Simply edit `PORTFOLIO_DATA` to tailor it with your own name, projects, and contact channels.
